# First three posts

Post these as Reels. Download each one from the site's player with **Download MP4 → 1080 × 1920**. It comes with sound and loops seamlessly.

**Post them in this order:** Bloom, then The Hill, then One More. Instagram puts the newest post first, so One More ends up top-left on your grid. It's about scrolling, which is exactly what someone on Instagram is doing, so it makes the best first impression.

Season 1 (The Cloud, The Seed, The Gap) now exports MP4 with sound too, so those can be your next three posts.

## Highlight covers

Add these when you make each highlight: tap **Edit cover** and pick the PNG. Each label fits Instagram's 15-character limit.

| File | Highlight name | Put in it |
|---|---|---|
| `hl-episodes.png` | `episodes` | Each new episode, shared from the Reel |
| `hl-wobbin.png` | `wobbin` | Character bits: the hop, the walk, close-ups |
| `hl-quotes.png` | `quotes` | The end-card quote from each episode |
| `hl-making-of.png` | `making of` | Sketches, timelapses, how the line is built |
| `hl-new.png` | `new` | Announcements and the latest episode |
